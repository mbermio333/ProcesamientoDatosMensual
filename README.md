Sistema de Generacion de Reportes SACER

*REQUISITOS 
El programa requiere antes de la instalación tener en el sistema la versión de python 3.8.3 para funcionar.
https://www.python.org/downloads/release/python-383/+

*INSTALACION
Para instalar el programa tenemos que ejecutar el archivo installer.bat, el cual copiará dentro de la carpeta de  LOCALAPPDATA del usuario del sistema todos los archivos necesarios del programa.
